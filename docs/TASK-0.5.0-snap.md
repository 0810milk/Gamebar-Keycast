## 0. 需求一句话
拖动自定义控件位置、或拖拽缩放控件大小时，系统根据**周边已存在控件**的空间关系，在**十字方向（上下左右）做边对边网格吸附**，帮用户排版对齐；吸附是**软性**的，随时可继续拖开，不锁死。

## 1. 用户已拍板的三项决策（必须遵守）
1. **吸附参考线**：要。浅蓝色 `#4A9EFF` 虚线，仅在吸附发生时显示，松手/脱离即消失。这是提升专业质感的反馈。
2. **吸附对象范围**：**所有自定义控件之间互相吸附，且必须能与内置默认键（QWER / ASDF / 修饰键 Shift/Ctrl/Alt / 空格）对齐**。布局是混合的，不能只对自定义控件生效。
3. **吸附阈值默认值**：接近 **8px** 触发吸附，偏离 **10px** 松开。Figma 同款手感，后续按实机反馈微调。

## 2. 吸附规则（详细规格）

**参照系**：除"正在操作的那个控件"外的全部按键（`_keys` 内置 + `_mouse` 鼠标 + `_customKeys` 自定义，所有在布局面板上的 Border）。

**两条轴独立判断**（水平轴：左右边缘；垂直轴：上下边缘），可同时生效（既贴左邻边又贴上邻边）。

**移动吸附（边对边 + 十字相对）**：
- 拖动中的控件 A，其四条边分别检查与"其他控件"的对应边距离：
  - A.右边缘 vs 对方左边缘（A 在左、对方在右）→ 水平吸附
  - A.左边缘 vs 对方右边缘（A 在右、对方在左）→ 水平吸附
  - A.下边缘 vs 对方上边缘 → 垂直吸附
  - A.上边缘 vs 对方下边缘 → 垂直吸附
- 任意一条边距离 ≤ **SNAP_NEAR (8px)** → 将该边修正到"精确贴齐"（距离归零），其余轴不受影响（只修正吸附到的那条边）。
- 只在坐标上修正 `_moveKey` 的 `Margin.Left/Top`（移动模式），不影响 Width/Height。

**软吸附（可拉开）**：
- 吸附发生后，若用户继续拖动使该边偏离超过 **SNAP_RELEASE (10px)** → 解除该轴吸附，恢复自由移动。
- 实现建议：吸附后每帧比对"指针累计偏移"与"吸附位置"，超过 10px 即松开。
- 绝不允许"吸附后无法拖走"：只要用户持续拖动且超过脱离阈值，永远能拉走。

**缩放吸附（边对边）**：
- 拖拽缩放时（`Key_PointerMoved` 的 `_dragKey` 分支，`_dragMode` l/r/t/b/tl/tr/bl/br），被调整的边（对应 mode）在接近其他控件对应边 ≤ 8px 时，吸附到贴齐边；同时更新 Width/Height/Margin 保持一致。
- 缩放仍受 `MinKeyW/MinKeyH` 最小尺寸保护（现有逻辑），吸附修正不得缩破最小值。

**吸附参考线**：
- 吸附生效时，在对应轴上画一条 `<Border>`/`<Line>`（浅蓝 `#4A9EFF`，虚线，1px，覆盖吸附重叠的边缘全长）。
- 多条边同时吸附时允许多条参考线（限少量，如 ≤4 条，避免杂乱）。
- 松手（`Key_PointerReleased`）或脱离（>10px）时隐藏并移除。
- 参考线置于布局面板之上（`ZIndex` 高于按键），不参与吸附计算、不拦截指针。

## 3. 代码接入点（已在 Widget1.xaml.cs 确认）
- **新增常量**：`SNAP_NEAR = 8`, `SNAP_RELEASE = 10`, `SNAP_LINE_COLOR = #4A9EFF`。
- **新增方法建议**：
  - `Border GetSnapTarget(double edge, ...)` / `double? ComputeSnap(Thickness candidate, out ...)` —— 核心吸附计算（十字轴、周边控件枚举、边对边判定）。
  - `void ShowSnapLine(side, x/y, length)` / `void HideSnapLines()` —— 参考线。
- **Key_PointerMoved（约 L1140）**：
  - `_moveKey` 分支（约 L1144-1151）：计算候选 margin → 调用吸附 → 写回 `_moveKey.Margin` + 显示参考线。
  - `_dragKey` 分支（约 L1159-1185，缩放）：在算出 w/h/ml/mt 后、赋给 Border 前，做对应边的缩放吸附修正。
- **Key_PointerReleased（约 L1191）**：落位前确保吸附结果已应用（持久化存吸附后坐标——现有 `CustomPos_`/`SaveKeyLayout` 逻辑不变，只需存吸附后的值）；隐藏参考线。
- **LongPress_Tick / CaptureLost / 缩放结束后**：确保参考线被隐藏（防残留）。
- **锁定状态**：`_layoutLocked` 时移动/缩放均不进入（已有逻辑），吸附自然不触发，无需改动。

**持久化**：完全复用现有 `CustomPos_<名>`（自定义）与 `Layout_<名>`（内置默认键），吸附只是移动过程中对坐标的修正，落位存修正后值即可。协议/配置不变。

## 4. 验收点（总管与用户逐条核对）
1. 拖一个自定义键靠近另一个自定义键左边，松手 → **右缘自动贴左缘**（水平吸附）；
2. 拖到某个键上方，松手 → **下缘贴上缘**（垂直吸附）；
3. 吸住后继续往反方向拖超 10px → **能正常拉开，不锁死**；
4. 拖到内置默认键（如空格/Shift）旁 → **也能对齐**（混合布局吸附）；
5. 拖拽缩放右边缘靠近右侧键左边缘 → **贴齐**；缩小不破最小尺寸；
6. 吸附发生时显示**浅蓝虚线参考线**，松手消失；
7. 锁定状态：移动/缩放不生效、无吸附、无参考线；
8. 吸附落位后关闭重开 widget → 位置持久化正确；
9. **每轮必须弹测试窗口**（AGENT-PROCESS.md §2 强制），用户实机体验①~⑦。

## 5. 约束
- 不引入第三方依赖；纯现有项目代码内实现（XAML 自行决定新建资源/直接在代码里建 Border）。
- 不动协议、不动布局持久化格式、不动现有交互（长按/右删/主题/锁定）。
- 性能：吸附计算在 PointerMoved 内完成，周边控件数量 ≤ 数十，无压力；参考线仅在吸附时创建，避免频繁无谓分配（可缓存/复用 4 条线对象）。
- 代码保持与现有风格一致（中文注释、`DiagLog` 可留调试行）。
