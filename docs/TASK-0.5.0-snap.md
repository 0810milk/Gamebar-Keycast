## 1. 鼠标垫（MousePad）长按移动 + 等比缩放

### 1.1 现状（冲突根源）
- `MousePad`（Widget1.xaml L87，80×80 Border，含 MousePadCanvas/MouseDot）不在 `_mouse` 字典，未挂 `AttachResize`。
- `UpdatePadSize()`（Widget1.xaml.cs 约 L499）**每帧**按屏幕纵横比设置 `MousePad.Width/Height`（`_padW/_padH` 缓存）。这就是"移动会被覆盖"的根源。

### 1.2 新行为
1. 给 `MousePad` 挂 `AttachResize`（复用长按移动/缩放/hover/锁定/吸附全套机制），`Tag="Pad"`。
2. **等比缩放**：`_dragMode` 任意边（l/r/t/b/tl/tr/bl/br）拖动时，鼠标垫宽高**同步按比例**变化（比例 = 拖动开始时 `_dragStartW/_dragStartH`）：
   - 拖右缘 r：左缘不动，w 变，h = w × (startH/startW)，**顶部不动**（mt 不变）；
   - 拖左缘 l：右缘不动，w 变，h 同步，顶部不动（ml 随 w 变化反推）；
   - 拖下缘 b：上缘不动，h 变，w = h × (startW/startH)，左边不动；
   - 拖上缘 t：下缘不动，h 变，w 同步，mt 随 h 变化反推；
   - 四角 = 对应两边组合，比例取主导轴（|dx| 与 |dy| 换算后取变化更大的轴决定缩放，保证比例一致不漂移）。
   - 最小尺寸保护：建议沿用 `ComputePadSize` 的最小值（MinW=40, MinH=36，等比缩放时同比例钳制）。
   - 实现建议：`AttachResize` 或 `Key_PointerMoved` 的 `_dragKey` 分支加 `_padEqualScale` 标志（或 `b == MousePad` 判断），在自由缩放计算后做等比换算；**不要动普通按键的自由缩放逻辑**。
3. **自动尺寸跟随的冲突处理**：
   - 新增 `_padCustomized` 标志：用户**首次移动或缩放**鼠标垫时置 true（并持久化 `PadCustom_=1`）。
   - `UpdatePadSize()` 开头：`if (_padCustomized) return;`（不再每帧覆盖用户尺寸）。
   - 用户落位/缩放结束时持久化：`PadPos_left`、`PadPos_top`（margin 值）与 `PadW`、`PadH`（尺寸，用 InvariantCulture）。
   - 启动恢复（OnLoaded/布局加载后）：读 `PadCustom_` 若为 1 → 应用保存的 Margin/Width/Height，`_padCustomized=true`；否则保持自动跟随现状。
   - ⚠️ 注意：MousePad 位于鼠标区 StackPanel 中，初始无 Margin——移动通过 `Margin.Left/Top` 偏移实现（与内置键移动同机制），初始值应为 (0,0,0,0)。
4. **重置鼠标垫**（`PerformLayoutReset` 内新增）：
   - 清除 `PadCustom_`、`PadPos_left/top`、`PadW/PadH`；`_padCustomized=false`；恢复 `UpdatePadSize` 自动跟随（立即用当前 vs 尺寸刷新一次）。

## 2. 添加控件菜单加「触摸板」

1. 87 配列布局（`KeyPickerScroll`，Widget1.xaml L169 起）底部加一个「触摸板」入口 Border（Tag="触摸板"，样式与布局内其他键一致，可放在最后一行独立或显眼处）。
2. 点击 → `AddCustomKey("触摸板")`：
   - `AddCustomKey` 加特判：`name=="触摸板"` 时 `Width=80, Height=80`（正方形），其余逻辑（去重/AttachResize/持久化/恢复 CustomPos_）与普通键**完全一致**。
   - 触摸板按键**自由缩放**（跟正常按键一样，不做等比）。
3. **反色安全**：渲染循环 `OnRendering` 用 `VkFromName(kv.Key)` 查 VK，「触摸板」无对应 VK——确保其恒视为未按下（VkFromName 对未知名返回越界值，或渲染循环对该名直接 down=false），**不得**因查找失败抛异常。
4. 右键删除/锁定拦截/吸附：与普通自定义键一致（AttachResize 已覆盖）。
