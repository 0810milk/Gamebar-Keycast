1.2.6（本地测试版）：组合模式手柄模板按参考图重做（实心机身 + 分层底座 + 按下强调色）

上一版模板是纯描边，与用户提供的参考图不符。本版按参考图重做为"实心"形态：
- 机身：一条闭合多边形填充（KeyBgB + 0.55 不透明度）+ 同点列描边（BorderB，2px）；
  下方左右握把向外扩、底部中央形成八字内凹缺口。
- 顶部：两个竖向胶囊框住扳机条；其下两个小胶囊框住肩键。
- 摇杆井（细外环 + 内部实心圆，两层灰）、十字键底盘（一体十字 / PS 四方块 / Switch 四圆点）、
  ABXY 大暗圆底盘 + 四个小圆、中央 Guide 圆环 + 一排三个小图形（View / 上传箭头 / Menu）。
- 待机灰层次、按下走强调色（AccentB）：肩键、扳机（值过阈值）、ABXY 四位、
  PS/Switch 十字四向、View/Menu 小图形均可逐位点亮；文字仍由部件印（随键位风格自动变）。
- 三套差异：Xbox 宽体一体十字；PS 更窄长 + 四方块十字 + 中央触摸板 + ○✕△□ 四圆；
  Switch 偏方 + 十字四圆点 + 四圆（A 右 B 下）。
- 自定义模式仍不画任何模板；模板只在风格/主题/模式变化时重建，不参与每帧渲染。

UWP 包 2.2.4.0。
